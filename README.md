## About

I bring a developer's mindset to infrastructure — building robust, automated systems that scale. Transitioned from full-stack web development to infrastructure automation, combining software engineering best practices with IT operations.

Passionate about homelabbing, open-source tooling, and pushing the boundaries of what's possible with modern automation platforms.
